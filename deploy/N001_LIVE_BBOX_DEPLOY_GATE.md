# N001 실시간 YOLO JSON — 운영 연동 인수인계 (2026-11-02)

## 변경 경계
- **N001만** `OCTV_N001_LIVE_BBOX_ENABLED=1`일 때 표시 전용 YOLO 분석을 사용한다.
- N002 / N003 / UTIC, 기존 영상 MP4/Range 재생, 기존 탐지·검증·사건화·MCP·FCM 코드는 변경하지 않는다.
- 표시용 YOLO는 DB에서 활성 세션을 **SELECT**하기만 한다. 사건 테이블 수정/발송/저장은 하지 않는다.
- 로컬 테스트용 `RealtimeJsonOverlay`를 운영 관리자 JWT 보호 API에 연결했다.
- 라벨은 `flood NN.N%`만 표시한다. 추론 결과는 요청마다 새로 생성되는 JSON이다. 사전 JSON을 사용하지 않는다.

## 신규 서비스
`docker compose -f deploy/compose.prod.yaml --profile n001-bbox ...`의
`n001-bbox` 서비스. **기본 비활성**이고 메모리 1800MB, CPU 0.7core 제한.
`scripts.run_n001_bbox_display`은 승인된 N001 원본 MP4와 승인 모델 해시를 확인하고,
DB에서 활성 N001 시연 세션의 시작 시각을 읽는다. 실제 YOLO를 약 1초 간격으로
CPU 실행한 다음 전용 Redis 키 `octv:n001:display:bbox:v1`에 최근 탐지 결과만
저장한다(TTL 6초). 별도 컨테이너이므로 기존 사건 탐지 프로세스가 멈추지 않도록 제한한다.

API: `GET /api/demo/v5/n001-live-boxes/{id}` (CONTROL_ADMIN만 허용).
N001 활성 상태·세션·TTL을 확인하고 실제 YOLO JSON만 반환하며, 미작동 시 빈 목록.
웹에서는 0.5초마다 JSON을 조회하고 `video.currentTime`과 일치하는 결과만
1.35초 이내로 표시한다. 영상 FPS·속도·seek는 변경하지 않는다.

## 사용 전 필수 확인
1. Docker 이미지에 승인 N001 MP4/모델(호스트 read-only assets)이 존재하고 SHA256이 일치한다.
2. 운영 배포 전 **이전 정상 웹/API/analysis/cctv 컨테이너 이미지와 Compose 설정의 복구 수단**이 실제로 존재하는지 확인한다. 기존 누락 이미지 문제가 확인되어 현재 **배포 금지**이다.
3. 별도 검증 환경에서 `docker compose config`, API 관리자 인증, 프런트엔드 typecheck/build, N001 JSON 신선도, MP4 1배속과 dropped frames를 검증한다.
4. 운영에서는 각 컨테이너별 CPU/메모리 및 사건 탐지 지연/빈도를 **전후 비교**해 기존 탐지 성능이 떨어지면 표시 서비스부터 종료한다. CPU 0.7core 제한으로 로컬의 1Hz 추론이 유지되지 않을 수 있다.
5. 시연 원본과 모바일용 MP4의 실제 프레임 시각이 일치하는지 확인한다. 브라우저가 지연·시킹 실패하면 박스가 숨겨질 수 있다.

## 기능 활성화 / 안전한 롤백 지침
**명령어를 운영 서버에서 지금 실행하지 말 것.** 운영 이미지·환경 변수 복구 계획과 사용자 배포 승인이 확보된 이후만 진행한다.

- API 환경 플래그 `OCTV_N001_LIVE_BBOX_ENABLED=1` (기본 0), 서비스 프로필 `n001-bbox` 별도 시작.
- 화면에 문제가 생기면 **N001 표시용 사이드카 컨테이너만 중지**한다. 전용 Redis 키가 최대 6초 뒤 만료되면 인증 API가 enabled=false를 반환하고, 열린 웹도 기존 N001 오버레이(준비돼 있다면)로 자동 전환된다. 다른 카메라와 사건 탐지는 그대로 유지된다.
- 완전한 기능 비활성화 시에는 이후 계획된 안전한 API 재기동 시점에 `OCTV_N001_LIVE_BBOX_ENABLED=0`으로 되돌린다. 이미 배포된 전체 운영 이미지를 무리하게 재배포할 필요는 없다.
- 사이드카 중지는 운영 API·web·cctv·db 컨테이너를 내리지 않도록 해당 서비스만 대상으로 한다.
- 기존 서버 코드를 완전히 되돌리려면 정확한 이전 Docker 이미지 태그/다이제스트와 관련 서비스별 Compose 복구 절차가 사전에 보장돼야 한다. **현재까지 전체 롤백은 검증되지 않았다.**

## 실측 전 가정
- 로컬 Windows에서 1Hz 분석 + 500ms JSON 조회가 부드럽게 보였다는 사실은 검증됐다.
- 운영 DigitalOcean 싱가포르 CPU에 표시 전용 YOLO를 추가해도 동일한 영상 품질·분석 주기가 나올지는 아직 미검증이다.
- MCP 외부 수위/교통 제공자 연결 제한은 별개 문제이며 이 표시 수정으로 해결되지 않는다.
