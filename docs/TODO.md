# 팀 구현 영역

- 인증·회원가입·입력 검증·역할별 접근 제어
- 실제 사건 조회·필터·검색·서버 페이지네이션 및 업무 상태
- PostgreSQL Docker 실행 검증 후 FastAPI DB 연결·ORM·CRUD
- CCTV 스트림·YOLO 탐지·사건화 및 정오탐 재학습
- 기상·수위·교통·기관·지도·경로 API
- 위험도·우선순위·후보기관·경로 추천 및 LLM 근거
- 실제 기관 전달·지원요청 접수·알림 전송
- 실제 Android/iOS 재생·터치·화면 크기 검증
- 최종 수정 브랜치의 PR 검토 → 팀원 확인 후 main 병합 → 각 PC에서 git pull

UI 목업과 API의 데이터 계약을 정한 뒤 연결합니다. 현재 지도 좌표·통계·추천 순서는 준비된 목업이며 실제 계산이 아닙니다. 네비게이션 외부 앱 실행·업무 저장은 없습니다.
