# 검수 기록

검수일: 2026-09-27. Linux 컨테이너·Chrome 브라우저, Node 24.19.0 / npm 11.9.0.

## 실행 결과

| 항목 | 결과 |
|---|---|
| 신규 폴더 `npm ci` | 통과. npm이 생성한 루트 lockfile로 522개 패키지 설치 |
| `npm run typecheck` | WEB·MOBILE 통과 |
| `npm run build:web` | Vite 프로덕션 빌드 통과 |
| `npm run build:mobile:web` | Expo Web 번들 통과. 생성 파일을 브라우저에서 렌더링하여 검수 |
| `npm run build:mobile:native` | Android·iOS Hermes 번들 생성 통과. APK/IPA 아님 |
| `npm run preview:mobile:web` | 정적 Expo Web 빌드의 HTTP 200과 JS 진입점 확인 |
| WEB 개발 서버 | 실제 화면 로드·이동 확인. Backend·DB·키 없이 실행 |
| Expo 개발 서버 | 일반 모드에서 이 컨테이너의 네트워크 인터페이스 제한으로 Bonjour 시작 실패. CI/오프라인 모드에서는 Metro 시작 메시지 확인, 선택 DevTools GUI는 root 환경에서 실패. 일반 PC의 개발 서버 동작은 미검증. 정적 웹 미리보기 대안 제공 |
| SDK 의존성 | SDK57 공식 템플릿 조합 사용. 오프라인 `expo install --check` 통과. 온라인 검사는 네트워크 제한으로 미검증 |
| Backend 의존성 | requirements의 버전 존재·의존성 해결을 pip dry-run으로 확인. Python 서버 실행 자체는 미검증 |
| 기능 범위 | 소스 검토 + `npm run check:scope` 통과. 네트워크·영속 저장·인증·자동 입력 검사·점수 계산 없음 |
| DDL | 빈 PGlite 0.5.8 / PostgreSQL 18.3 WASM에서 14테이블·134컬럼·20FK 생성. FK·NOT NULL·ENUM 거절과 IDENTITY 발급 확인 |
| Git 제외 | .env·node_modules·dist·모델 가중치는 제외. .env.example·lockfile·소스·작은 UI 영상은 포함 확인 |
| PPTX | 9장 렌더 검수. 기본 도형/텍스트 136개, 커넥터 36개(양 끝 도형 연결), 이미지 0개. 패키지·레이아웃 검사와 재가져오기 통과 |

- WEB 9개 화면: 로그인·회원가입·통합관제·사건·기관별 경로·CCTV·통계·설정·CCTV 대상.
- MOBILE 12개 화면/탭: 로그인·가입 3단계·홈·알림·목록·사건 정보·영상·경로·추가 요청·설정.
- 빈 입력으로 로그인·가입 이동, 고정 가입 완료 예시, 기관 체크와 다른 기관 경로 조회의 독립 상태, 전달 확인 후 상태 불변을 확인했다.
- A/B/C 강조·영상 탭·요청 확인/이탈 확인·설정 저장 확인·로그아웃 확인·알림/사건 카드 이동을 눌러 확인했다.
- 연결이 끊긴 CCTV-023은 WEB과 MOBILE 영상 탭에서 같은 상태를 표시한다. 기본 활성 토글은 연결 상태를 변경하지 않는다.
- 로고·도로 이미지·배경 동영상은 정상 표시되었다. 검색/필터/페이지 선택은 실제 데이터를 가공하지 않음을 소스로 확인했다.

## CMD 안내 개정 (2026-09-27)

README·UI 실행·GitHub·Backend·DB 안내를 CMD 문법으로 맞추고 설치 및 빨간 줄 확인 순서를 추가했다. 실행 보조 파일은 `.cmd`로 제공한다. 이번 개정은 문서·실행 보조 파일·줄바꿈 설정만 변경하며 UI 소스·의존성·DDL·PPTX·첨부 원본은 유지한다. 위 실행 결과는 기존 패키지 검수 기록이며, 이번 개정에서는 변경 범위와 ZIP 무결성을 확인한다.
