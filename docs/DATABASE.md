# PostgreSQL DDL

## 실행
UI와 DB는 연결되어 있지 않다. PostgreSQL 서버·사용자 생성은 팀에서 수행한다.
**빈 개발 DB**를 지정하고, octv 루트 CMD에서 실행한다. 아래 `octv_dev`는 이미 존재하지 않는 새 DB 이름이어야 한다. `createdb`·`psql` 명령을 찾지 못하면 PostgreSQL 설치 폴더의 `bin`이 PATH에 있는지 확인한다.

```cmd
createdb -U postgres octv_dev
psql -U postgres -d octv_dev -v ON_ERROR_STOP=1 -f "database\schema.sql"
```
기존 DB 이름으로 바꾸어 무심코 실행하지 않는다. 스크립트에는 DROP·TRUNCATE·초기화가 없다.
중복 실행하면 기존 타입/테이블로 오류가 나며 트랜잭션이 롤백된다.

## 기준·생성 순서
첨부 `references/ERD.png`만 기준으로 14개 테이블·134개 컬럼·20개 FK를 전사했다.
선행 테이블부터 생성: region, agencies, users, cctvs, monitoring_settings, incidents, weather_alerts,
incident_contexts, incident_assessments, incident_agency_recommendations, route_evaluations,
route_candidates, notifications, incident_support_requests.
컬럼별 대응은 `DB_COLUMNS.md`, 기계 판독 가능한 전사는 `database/erd-transcription.json`.

## 최소 변환
| 원본 | PostgreSQL / 처리 |
|---|---|
| AUTO_INCREMENT | BIGINT GENERATED BY DEFAULT AS IDENTITY + PK |
| DATETIME | TIMESTAMP WITHOUT TIME ZONE |
| ENUM(...) | CREATE TYPE ... AS ENUM, 원본 값·순서 유지 |
| DECIMAL / INT / BOOLEAN / JSON | 그대로 사용 |
| CURRENT_TIMESTAMP / TRUE / FALSE | 기본값 그대로 유지 |
| incident_agency_recommendations.agency_id = BIGBT | 존재하지 않는 타입. 참조 PK와 같은 BIGINT로 최소 수정 |
| Domain / Default value 회색 글씨 | ERD 편집기 자리표시자. SQL 타입·기본값으로 만들지 않음 |

## 확인사항
- 이미지에서 별도 UNIQUE·CHECK는 확인되지 않아 임의 추가하지 않았다. email·incident_no·dedup_key에도 UNIQUE를 만들지 않았다.
- FK 삭제/수정 정책이 명시되지 않아 PostgreSQL 기본 NO ACTION이다.
- 선이 겹친 관계는 FK 아이콘·컬럼명·참조 PK를 함께 대조했다. `responder_id → users.id`, `updated_by → users.id` 포함. 원본 DDL이 생기면 최종 비교 권장.
- 원본의 `notifications.incidents_id` 복수형 컬럼을 그대로 유지했다.
- DATETIME은 시간대 없는 값이다. 운영 시 Asia/Seoul 등 저장 정책을 팀이 정해야 한다. 자동 UTC 변환을 추가하지 않았다.
- `updated_at`은 생성 기본값만 있다. 갱신 트리거는 작성하지 않았다.
- 프론트의 `SEL-001`, `CCTV-012`, 점수 퍼센트 등은 화면 표시용이다. DB BIGINT ID와 0~1 DECIMAL 값을 그대로 대체하지 않는다.

검증: 빈 PGlite(PostgreSQL 18.3 WASM) DB에서 생성, FK·NOT NULL·ENUM·IDENTITY 확인.
네이티브 PostgreSQL 서버 및 사용자 PC의 psql 실행은 미검증. 계정·사건 seed는 제공하지 않는다.
